# Gerenciador de Despesas

Aplicativo mobile em React Native com Expo. As despesas ficam salvas localmente no dispositivo.

## Executar

1. Instale o Node.js (versão LTS) e o aplicativo Expo Go no celular.
2. Na pasta do projeto, instale as dependências:

   ```sh
   npm install
   ```

3. Inicie o Expo:

   ```sh
   npx expo start
   ```

4. Escaneie o QR code exibido no terminal usando o Expo Go. Para usar um emulador Android, abra-o antes e pressione `a` no terminal do Expo.

Para encerrar, pressione `Ctrl+C` no terminal.
